班级公布栏 v1.0.5 · 免安装版（64 位 Windows）
================================================

【登录与身份】
程序分四种身份，同一台电脑登录不同账号就是不同身份：
  - 管理员：改课表 / 导数据 / 发布 / 改设置 / 管理账号。你原来那个账号升级后就是管理员，
            用户名和密码都没变。
  - 班主任：改自己班的课表与作业、缺交名单，可收发数据包（在「用户管理」里给账号填上班级）。
  - 科任老师：只能看课表，可编辑自己所教班级的作业公示与缺交名单。
  - 电教管理员（学生）：控本机显示 + 改本班课表，改不了其他数据。

用班主任 / 科任老师 / 电教管理员账号登录后，课表会自动切到他所属的那个班；
管理员保持上次选择的班级。

开机自动登录用的是 local（密码 000，电教管理员）—— 教室机平时就是这个身份，
学生乱点也改不坏东西。要改设置、导课表，到「用户中心 → 切换账号…」用管理员登录，
改完再切回来即可，不用重启程序。

用户管理：用户中心 →「用户管理…」，可新增账号、改角色、重置密码，
也可以「从 Excel / CSV 导入名单」，列顺序是：
  用户名 | 显示名 | 角色 | 班级 | 密码
（角色写 管理员 / 班主任 / 科任老师 / 学生，或 admin / teacher / subject / student）

注意：这里的权限是"界面上不给入口"，不是加密防护 —— 会改文件的人照样能绕过，
它的作用是防误操作和防学生乱点。另外班主任改的课只在本人这台机器生效，
不会自动回传到主机。

【角色权限（v1.0.5 更新）】
管理员可以配置三个角色能做什么：用户中心 →「用户管理…」→「角色权限…」。
可勾选的能力（管理员恒为全权，不在此表）：
  编辑课表、作业与缺交名单、恢复被停用的调课、导入临时课表、
  数据包导入导出 + 备份恢复、导入总课表 / 清除调课、发全校通知、自动更新设置。
  - 出厂默认：班主任 = 改课表 / 作业缺交 / 恢复停用 / 数据包备份 / 自动更新；
              科任老师 = 只有作业缺交 + 自动更新；
              电教管理员 = 改本班课表 / 作业缺交 / 恢复停用 / 自动更新。
  - 「发全校通知」默认只有管理员有：全校通知会同步到所有教室机，本班通知只留本机。
    需要时可在角色权限里给班主任或电教管理员授权。
  - 权限随数据包下发，只有"发布机"能改；其他机器此窗口只读（在那改了会被下次同步覆盖回去）。
  - "发布"与"管理用户"两项刻意不开放：发布一次影响 30 台且无法回滚，管理用户等于能把自己升成管理员。
  - "自动更新设置"默认对所有角色开放，但非管理员只能改共享文件夹 / U 盘 / FTP 与检查频率，
    "这台是发布机"及其专属项为只读 —— 防止教室机误变成发布机往数据源写数据。
  - 每次保存都会记一条「权限变更记录」（用户管理里可查看），配错了几周后才显形也能倒查是谁改的。


【怎么开始】
1. 把整个文件夹解压到教室电脑的任意位置（建议放到 D:\班级公布栏 之类不会被清理的目录，
   不要放在桌面或临时文件夹）。
2. 双击 ClassBulletinApp.exe 启动。首次启动会同时打开「控制面板」。
3. 控制面板 →「数据管理」标签页：
   - 点「导入总课表」，选择学校的「全校班级总课表.xlsx」；
   - 导入后在顶部下拉里选中自己的班级。
4. 顶部「课表悬浮」「通知悬浮」两个按钮可以随时开关课表 / 通知悬浮窗。

【日常怎么用】
- 课表悬浮窗：拖动标题条移动、拉边沿改大小，松手自动记住；
  拖到屏幕边沿会自动开启「自动靠边隐藏」，拖离边沿自动关闭。
  双击标题可以切换显示哪一天（调休上课也能显示）；
  右键 / 长按某节课可安排调课、代课。
  调过 / 代过的课会在科目同一行右侧挂一个小标签（「已调课」橙色 /「代课」蓝色），
  标签不占额外一行，课表格的高度与普通课完全一样，不会把整列课表挤下去。
- 通知悬浮窗：顶部单行字幕滚动播放；双击可编辑通知，右侧「隐藏」切换自动隐藏。
  字幕的字体 / 字号 / 字色 / 背景在控制面板「通知公告」页顶部调：字号有 20 多档（12～96），
  字色与背景各有十几种预设，还可以点「调色…」用系统调色板取任意颜色，改完立刻生效。
- 作业公示 / 缺交名单 / 自定义便签：都是屏幕上的便签，拖动摆放、拉边沿改大小、
  双击编辑；便签上有 🔒 按钮，锁定后不会被误移动或误改。
- 悬浮课表底部的快捷按钮（📋 作业 / 📝 缺交 / 📌 便签）：点一下就能直接打开对应的便签去改；
  「便签」打开的是自定义便签，一张都还没有时会直接新建一张并弹出编辑窗口。
  这一排的大小可以在底部「管理」窗口里调：选「自动」会跟着悬浮课表的宽度挑档位
  （窗口窄时收小，三个不会挤成两行；拉宽后放大一点），也可以固定成小 / 标准 / 大 / 特大 / 超大。
  标题栏右上角「更新课表」可立刻从数据源检查并应用最新课表，不用回控制面板翻菜单。
  执行中会显示「⏳ 更新中…」，成功后显示「✔ 完成」并在 4 秒后复原；失败也只是回到「更新课表」，
  **按钮随时可以再点一次重试**（不会一直红着挡住点击）。
  失败原因显示在课表下面的状态栏里：红色字「⚠ 更新失败：原因」会一直留到下一次更新成功。
  状态栏是一条滚动字幕，把「上次更新失败的原因」和「课表更新时间」连在一起循环显示；
  文字短的时候静止显示，长了才滚。没有相应权限的账号看不到这些按钮（整条自动收起）。
- 自定义便签：控制面板「便签管理」页点「＋ 新增 / 编辑自定义便签」，
  可写教师寄语、温馨提示等，支持多张并存。

【其它入口】
- 系统托盘图标：右键是精简菜单，默认只有「打开控制面板 / 用户中心 / 退出」。
  想加常用项（开关悬浮窗、桌面背景等）可在「显示设置 → ① 悬浮窗 → 任务栏菜单…」里自己配，
  可改文字、上下排序，最多 15 项。
- 开机自启：控制面板「设置」里可勾选（写入当前用户的开机启动项）。
- 「桌面背面」：把当天课表 / 作业 / 缺交名单 / 自定义便签直接画到桌面壁纸上（壁纸层，不挡操作）。
  最省事的用法是「设为背景」：把悬浮窗拖到想要的位置、拉到想要的大小，点右下角「设为背景」——
  一下就按当前的位置和大小锁进壁纸，同时作业 / 缺交 / 自定义便签自动隐藏、悬浮课表改为靠边自动隐藏，
  屏幕上不再重复显示同一份内容。想微调就点「位置」进排版窗口拖动。
  设好之后这个按钮会变成「还原背景」：再点一下即可撤掉壁纸内容、恢复系统原壁纸，
  同时把刚才藏起来的课表 / 便签放回屏幕。
  也可以在「显示设置 → ③ 界面主题 → 取消桌面背景（恢复悬浮窗）…」里取消，
  托盘菜单里同样有「取消桌面背景」（可在「任务栏菜单…」里加进去）。
  还可以到「布局设置 → 桌面背景」页逐项取消勾选（自定义便签在同一页逐张勾选）。
  壁纸上的字号与屏幕上悬浮窗**一样大**（已按系统缩放折算），不会因为设成壁纸就变大变小。
- 文字格式（作业公示 / 缺交名单 / 自定义便签的编辑窗口里）：
  可设「加粗」、字号（小 / 标准 / 大 / 特大 / 更小 / 超大 / 巨大 共 7 档）、
  颜色（12 种预设色块）；要别的颜色点旁边的「调色…」，用系统调色板任选，选过的颜色会留在下拉里。
  改格式时上方的输入框会立刻按新样式显示，不用关掉重开。
- 软件更新（只管程序本身的版本）：「关于」标签页里有当前版本与「检查更新」，
  点它会到 Gitee 仓库读取最新的发布版本；发现新版可直接点「下载最新版」下载安装包，
  或点「打开发布页（Gitee）」用浏览器查看全部版本。这里**不会自动替换程序**，
  也不影响课表数据的自动更新（那条走「数据管理 → 自动更新」，两者互不相干）。
  说明：Gitee 仓库若还是「私有」，教室机匿名读不到版本信息（会提示连不上 / 读不到），
  把仓库改成公开即可；不想改公开，也可以只在「关于」里点「打开发布页」用浏览器下载。
- 自动更新：数据管理 →「自动更新设置」，勾上「启用自动更新」并选好共享文件夹 / U 盘 / FTP。
  后台检查到新版本会**自动下载并应用**（先备份，失败自动回滚），无人值守也能更新。
  某台机器若收不到更新，多半是这里的来源路径被改过，用任意账号都能进去改回来。
- 共享访问设置向导（只有发布机需要）：数据管理 →「自动更新设置」→ 左下角「共享访问向导…」。
  它把"课表 Excel 放在哪、发布机怎么读到、数据包传到哪"三件事收成三步：
  ① 办公电脑准备 —— 建专用账号、开共享、给「更改 / 修改」权限。页面上的命令可一键复制，
     粘到办公电脑的管理员命令提示符里执行即可（只需做一次）。
     权限必须是"更改（共享）+ 修改（NTFS）"：只读的话发布机能读课表，但人往共享目录里
     拖课表会被拒绝；完全控制则多给了改权限的钥匙，没必要。两层取交集，缺一层都不行。
  ② 本机凭据 —— 填账号密码后点「测试并保存凭据」。它会先断开到办公电脑的旧连接（换账号后
     旧会话仍挂在老身份上，不断开会测出假成功），再真的读一次目录并报出 xlsx 个数，
     最后做一次写测试，直接告诉你"能不能把课表拖进来"。密码只进 Windows 凭据管理器，
     不写进程序配置，也不随数据包下发。
     这一页还有「打开共享目录」「映射为网络驱动器」两个按钮：后者会给共享分一个盘符（自动挑空的），
     方便在资源管理器里拖文件。注意盘符只用于手动拖文件，程序里的「发布源目录」仍要写
     \\办公电脑\dfzx\source 这样的完整路径 —— 盘符在开机早期和计划任务里是看不到的。
  ③ 数据通道 —— 选"用学校现成的 FTP"或"以后由办公电脑自己提供 FTP"，填地址 / 账号 / 密码。
  点「完成并保存」会顺手把「发布源目录」和「数据源」填好，不用再去另一页手输。
  注意：三台发布机用的是**不同 Windows 账号**，凭据按账号隔离，所以第 ② 步要在每台机器上各做一次；
  教室机完全不用做 ① ②，只填 FTP 即可（它们不读共享目录）。
- 共享目录里的「副本」文件会被自动跳过：两个人同时打开同一份 Excel 时，Excel / WPS 会生成
  「xxx (用户的冲突副本).xlsx」「xxx - 副本.xlsx」这类文件。它们不是真课表，发布时会被忽略，
  并在发布结果里列出来提醒你去清理。看到这类提示就进共享目录把副本删掉，只留正本。

【数据存在哪里】
- 课表、通知、作业、便签、账号与所有设置都保存在：
  %APPDATA%\ClassBulletinApp （即 C:\Users\用户名\AppData\Roaming\ClassBulletinApp）
- 卸载 / 换版本不会丢失数据；如需彻底重置，退出程序后删除该文件夹即可。

【常见问题】
- 提示缺少 DLL 或无法启动：请确认是 64 位 Windows 10 及以上系统；
  本版本已自带 .NET 8 运行时，不需要另外安装。
- 升到 v1.0.3 后打不开设置页 / 按钮是灰的：当前身份是电教管理员（或游客），
  到「用户中心 → 切换账号…」用管理员账号登录即可。
- 自己改的调课突然不显示了：主机开启了「覆盖本机手工调课」策略。
  记录没有被删除，可在「数据管理 → 恢复被主机停用的本机调课…」里恢复。
- 发布时提示「发布源目录不存在」：这个格子填的是【文件夹路径】，例如 \\ZENGSIR\dfzx\source
  或 D:\dfzx\source，不是 FTP 地址 —— FTP 上没有课表 Excel，Excel 永远留在共享目录里，只传打包后的数据包。
  ★ 也不要用向导映射出来的盘符（如 Z:\）：盘符只在当前登录会话里有，开机早期和计划任务看不到它，
  填成盘符就会出现"别的机器都在更新，这台一直说源目录不存在"。
  不确定怎么填就点「自动更新设置 → 共享访问向导…」，它会算好并直接写进去；
  也可以直接点这一行右边的「浏览…」选文件夹（要从资源管理器「复制路径」粘过来也行，程序会自动去掉引号）。
  如果填的确实是共享路径仍然报错，说明这台机器读不到那个共享（权限没给、账号密码不对，或凭据没存），
  向导第 ② 步的「测试并保存凭据」会给出具体是哪种原因。
- 打开程序时状态栏出现红字「⚠ 读不到发布源目录 …」：这台机器勾了「本机兼任发布机」，
  但程序读不到那个目录，自动发布已经停摆 —— Excel 改了也不会传给其他教室机。
  程序会在红字里直接给出原因（找不到网络路径 / 共享名不存在 / 拒绝访问 / 账号密码不对 / 凭据冲突），
  照着那一句去处理即可；目录恢复可读后红字会自动消失，不用手动清。
  最常见的三种：办公电脑关机或改了 IP、共享被停掉（在办公电脑执行 net share 确认）、凭据失效。
- 发布时报「拒绝访问」或「1219」：前者是共享权限 / NTFS 权限没给到该账号；
  后者是这台机器之前用别的账号连过同一台服务器，先在命令提示符执行
  net use \\办公电脑名 /delete 再重试（向导第 ② 步点「测试并保存凭据」时已自动断开一次）。
- 往共享目录里拖课表，提示「需要权限才能执行此操作」：这个账号没有写权限。
  共享权限要给「更改」，NTFS 要给「修改」，两层都要（只给一层等于没给）。
  Excel 保存网络文件是"写临时文件 → 删原文件 → 改名"，所以必须带删除权限，
  只勾「写入」不勾删除，文件能建但保存会失败。
- 发布结果里出现「已跳过 N 个副本文件」：共享目录里有 Excel 冲突副本。
  进共享目录把它们删掉、只留正本即可；不删也不会发错，只是会一直提示。
- 想彻底卸载：删除本文件夹，并在「设置 → 应用」里卸载（安装版才有此项）。
