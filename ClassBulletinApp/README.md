# 班级公布栏（ClassBulletinApp）

为教室多媒体屏幕设计的**班级公布栏**：导入全校总课程表 Excel → 选择班级 → 自动显示该班**当日课表**（含当前课高亮、单双周课标注、临时调课覆盖）→ 显示**通知/公告**。

技术栈：.NET 8 + WPF（Windows 10 桌面应用）。

## 功能一览
- 导入全校总课程表（xlsx），自动识别各班与每天 8 节课、大课间、眼保健操，解析科目 / 教师 / 地点 / 单双周 / 调代课标记。
- 按当天星期自动显示当日课表，**当前正在上的课高亮**，单双周课标注（单周 / 双周）。
- **临时调课 / 代课覆盖**：双击任意一节课弹出编辑对话框（含「保存(确认)」/「取消」/「清除调课」按钮），临时替换内容（科目 / 教师 / 地点 / 备注），优先于总课表显示并标注「已调课」，可随时清除恢复。
- **单双周校正**：在设置里指定「开学第一周星期一」，把单/双周与学校实际教学周对齐（留空则按系统日历周估算）。
- **通知 / 公告**：增删通知，支持「置顶」（置顶项始终排在前面）。
- **课表与通知分开显示**：课表和通知是两个独立的**悬浮窗**，可分别设置：
  - 贴边位置（左 / 右 / 上 / 下 / 居中）；
  - 显示大小（宽 / 高，通知还可设条高与字号）；
  - 整体透明度（0.2~1.0）；
  - 置顶显示；
  - **鼠标穿透**（点击落到底层窗口，纯展示）或 **自动靠边隐藏**（窗口完全移出屏幕，鼠标移到 / 手指触到屏幕边沿才滑出）——二者互斥；
  - 通知默认在**顶部单行字幕（跑马灯）**滚动显示，可调速。
- **上下课提醒（独立「提醒设置」标签页）**：课前 / 上课 / 下课 / 放学自动弹窗，可设提前分钟数、弹窗秒数、提示音；**语音播报**（Windows SAPI，设为「系统默认」时自动优先中文语音）可单独开关，并可选具体语音、语速、音量，支持「试听」。
- **桌面背面（当天课表 + 作业公示）**：把当天课表与作业公示绘制成一张桌面壁纸，位于所有窗口之下，不遮挡也不影响操作；两块内容可**同屏显示**，位置（九宫格锚点 + 像素偏移）与宽度**各自独立调整**，底图可沿用系统原壁纸；课表 / 作业内容变化或跨天会自动重绘。
- **快捷开关桌面背面**：悬浮课表最下方按钮、任务栏图标右键菜单都能一键开关「当天课表 → 桌面背面」。
- **教室部署自动化**：全屏展示、防误触锁定、开机自启、启动即全屏/锁定；程序常驻**系统托盘**（双击图标或右键菜单打开控制面板 / 开关悬浮窗 / 开关桌面背面 / 退出），一台机器一台班、多班多台各自配置。

## 工程结构
- `ScheduleCore/`：核心库（与界面无关）
  - `Models/`：Lesson / ClassSchedule / ScheduleFile / Notification / AppSettings / **LessonOverride（调课覆盖）** / **PanelLayout（悬浮窗布局）** / **ReminderSettings（上下课提醒 + 语音）** / **BackdropSettings（桌面背面）**
  - `Services/`：ScheduleImporter（解析 xlsx）、Store（JSON 持久化到 AppData）、WeekHelper（单双周，支持学期起始日）、TeacherExtractor / TeacherOverrideApplier（教师个人课表）
- `ClassBulletinApp/`：WPF 主程序
  - `MainWindow`：控制面板（标签页：周课程表 / 数据管理 / 显示设置 / 提醒设置 / 桌面背面 / 通知公告 / 作业公示 + 托盘）
  - `ScheduleWindow`：**课表悬浮窗**（按布局定位 / 缩放 / 透明 / 置顶 / 穿透 / 靠边，可双击调课，底部一键切换桌面背面）
  - `NotificationWindow`：**通知悬浮窗**（顶部字幕跑马灯）
  - `LayoutWindow`：**布局与显示设置**（课表 / 通知各自的位置、大小、透明度、置顶、穿透、靠边、露出像素、边沿感应宽度、字幕速度）
  - `ReminderService` / `ReminderPopup` / `VoiceSpeaker`：上下课提醒（轮询今日课表）+ 置顶弹窗 + 语音播报
  - `BackdropService` / `BackdropRenderer`：桌面背面（课表 + 作业合成壁纸、原壁纸底图、自动重绘、应用 / 清除）
  - `LessonOverrideWindow`：临时调课编辑对话框（保存 / 取消 / 清除）
  - `SettingsWindow`：单双周校正 + 开机自启 + 启动全屏/锁定
  - `FloatingHelper`：鼠标穿透（P/Invoke）、按锚点贴边定位、自动靠边隐藏
  - `BoardBuilder`：生成当日课表（主窗与悬浮窗共用）
  - `AppEvents`：跨窗口事件（课表/通知/布局变化通知）
- `ParserTest/`：控制台验证程序（对真实总课表跑一遍解析）
- `installer/`：Inno Setup 安装包脚本 `ClassBulletinApp.iss` 与一键编译 `build_installer.bat`

## 如何构建 / 运行
需要 .NET 8 SDK（本机已装在 `F:\dotnet8\`）。

```bat
F:\dotnet8\dotnet.exe restore
F:\dotnet8\dotnet.exe build ClassBulletinApp\ClassBulletinApp.csproj -c Release
F:\dotnet8\dotnet.exe run --project ParserTest   :: 验证解析结果
```

## 如何导入课表
1. 启动程序，点击右上角「导入课表」。
2. 选择工作空间里的 `全校班级临时总课表.xlsx`。
3. 导入成功后，顶部「班级」下拉会列出全部班级，选择即可；选择会被记住（每台机器各自记住自己的班）。
4. 总课表是「临时」表，更新后重新导入即可覆盖（覆盖不影响已设置的临时调课）。

## 快捷键 / 操作
| 操作 | 快捷键 / 按钮 |
| --- | --- |
| 全屏 / 退出全屏 | `F11` 或「全屏」按钮 |
| 防误触锁定 / 解锁 | `Ctrl+L`（锁定时隐藏鼠标并吞掉点击，仅响应快捷键） |
| 锁定下解锁 / 全屏下退出 | `Esc` |
| 编辑某节课（临时调课） | 双击控制面板或课表悬浮窗中的该节课卡片（弹出含「保存/取消」的对话框） |
| 显示 / 隐藏课表或通知悬浮窗 | 控制面板顶部「课表悬浮」「通知悬浮」按钮，或托盘右键菜单 |
| 布局与显示设置 | 控制面板「布局设置」按钮（位置 / 大小 / 透明度 / 置顶 / 穿透 / 靠边 / 字幕速度） |
| 打开控制面板 | 双击系统托盘图标，或右键菜单「打开控制面板」 |
| 隐藏到托盘（后台常驻） | 控制面板「隐藏到托盘」按钮 |
| 开机自启 / 启动全屏 / 启动锁定 | 「设置」按钮中勾选 |

## 部署到教室机（Win10）
### 方式一：绿色自包含（直接拷贝）
发布为自包含程序，拷贝到教室机直接运行，无需安装 .NET：

```bat
F:\dotnet8\dotnet.exe publish ClassBulletinApp\ClassBulletinApp.csproj -c Release -r win-x64 --self-contained true -o publish
```

`publish/` 目录即为可拷贝的绿色程序（`ClassBulletinApp.exe`）。

教室部署建议：
- **开机自启**：「设置」中勾选「开机自动启动」（写入当前用户 `Run` 注册表）；或用方式二安装包。
- **全屏展示**：`F11` 或「全屏」按钮（无边框最大化）。
- **防误触锁定**：`Ctrl+L` 进入锁定，鼠标被隐藏且点击无效，避免学生误操作；`Ctrl+L` 或 `Esc` 解锁。
- **课表 / 通知悬浮窗**：点击控制面板顶部「课表悬浮」「通知悬浮」开关；用「布局设置」把课表放到右侧、通知放到顶部字幕条，并调到合适的透明度与大小。
- **鼠标穿透 vs 自动靠边隐藏**：纯展示时勾选「鼠标穿透」（点击落到底层，互不干扰）；若希望屏幕边缘留出空间，勾选「自动靠边隐藏」（鼠标靠近边缘时滑出）。二者互斥，只能选其一。
- **启动即展示**：「设置」勾选「启动即进入全屏/锁定」，并勾选「启动后自动弹出悬浮窗」，配合开机自启可实现开机自动进入展示模式；控制面板可「隐藏到托盘」常驻。
- **多班多台**：每台机器导入同一份总课表，各自选择本班、各自配置悬浮窗布局并保存即可。

### 方式二：安装包（Inno Setup）
`installer/ClassBulletinApp.iss` 会把 `publish/` 下的自包含程序打包成标准 Windows 安装包（开始菜单 + 桌面快捷方式 + 可选开机自启 + 卸载）。

构建步骤（需在装有 Inno Setup 6 的机器上执行）：
1. 先按方式一执行 `publish` 生成 `publish/` 目录。
2. 双击运行 `installer/build_installer.bat`（自动查找 ISCC 编译器并编译）。
3. 生成的 `setup.exe` 位于 `installer/Output/`。

> 若未安装 Inno Setup，脚本会提示你到 https://jrsoftware.org/isdl.php 下载安装。

## 数据存放位置
所有数据以 JSON 存于当前用户 `AppData\Roaming\ClassBulletinApp\`：
- `schedule.json`：导入的总课表
- `overrides.json`：临时调课覆盖
- `notifications.json`：通知/公告
- `settings.json`：选中的班级、学期起始日、开机自启、启动全屏/锁定、悬浮窗开关，以及**课表/通知悬浮窗的布局（位置/大小/透明度/置顶/穿透/靠边/字幕速度）**

每台机器数据独立，便于多班多台分别配置。

## 已知限制 / 后续可扩展
- 通知目前为手动录入；后续可支持从文件/后台批量导入、定时公告、放学提醒等。
- 可参考同工作空间的 `ClassIsland-master` 实现天气、主题、自动化等增强。
- 锁定模式为纯展示（鼠标点击被吞掉）；如课表超出一屏需滚动，解锁后操作即可。
