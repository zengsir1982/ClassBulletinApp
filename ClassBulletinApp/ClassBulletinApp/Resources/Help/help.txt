== start | 第一次用，从这里开始 | quick | 登录、认识主界面、三个常用按钮
装好之后，桌面上会有「班级公布栏」。双击打开，先登录（教室机开机一般会自动登录成 `电教管理员`）。

## 主界面只看三处

- 左边五个字：`今日` `课程表` `内容` `消息` `设置`。日常 90% 的事只在前两个。
- 中间是内容区，`今日` 页给你四张卡：今天的课、待办、班级速览、常用动作。
- 顶部一行按钮，最右边是当前登录的人，点它可以切换账号。

![](today.jpg)
△ 今日页：四张卡片各管一件事，右下角是这几个按钮

## 三个最常用的按钮

1. 要发作业或通知 → 点 `发布内容`（在今日页右下）。
2. 要暂时不让人点 → 按 `Ctrl + L` 锁定，再按一次解锁。
3. 找不到功能 → 按 `F1`，就是这份帮助。

!> 改课表、导数据要用管理员账号。用 `设置 → 用户中心 → 切换账号…` 换过去即可，不用关程序。

（帮助里的截图都用了**示例姓名和示例地址**，老师和班级不是学校里的真人。）

== schedule | 我要改一节课（调课 / 代课） | quick | 拖动交换两节课，右键安排调课代课
## 最快的方式：拖动

1. 点左边 `课程表`。
2. 按住一节课，拖到另一节上，松手 —— 两节课就换了。

![](schedule.jpg)
△ 周课程表：整周一眼看全，拖动即可交换

## 只改某一天（调课 / 代课）

1. 在那一格上 **点右键**。
2. 选「安排调课 / 代课」，填上那天实际上的科目和老师。
3. 只影响这一天，基础课表不动。

## 改错了想恢复

- 单格：右键 → 清除安排。
- 整批：`设置 → 数据管理 → 清除临时调课 / 代课…`，可以按本周 / 指定范围 / 全部清。

!> 学校临时放假、周六补周三的课，别一格一格改 —— 用 `设置 → 数据管理 → 校历 / 调休`，一次说清哪天按哪天上课。

== publish | 我要发今天的作业 | quick | 一次发给一个或多个班，教室机自动显示
1. 点今日页右下 `发布内容`（或 `内容 → 发布信息`）。
2. 上面选班级：点 `＋ 增加班级`，一次可以选好几个班，一张单子一起发。
3. 内容类型选 `作业公示`，再选科目、填入今天的作业内容。
4. 点右下 `发布信息`。

![](publish.jpg)
△ 发布信息：班级、类型、内容三样填完就能发

## 发完怎么确认到了

发出去不是结束，教室机还要收下。看 [我怎么知道教室机收到了](topic:ledger)。

!> 勾了 `⚡ 直接增加` 会跳过电教管理员的确认，教室机直接显示。第一次用先别勾，见过一次确认流程再决定。

== notice | 我要发一条通知 | quick | 本班通知立刻显示，全校通知要走发布
1. `发布内容` → 内容类型选 `本班通知`。
2. 填标题和正文。要念出来就勾 `🔊 语音提醒`。
3. 点 `发布信息`。

![](notice.jpg)
△ 通知公告：本班通知发完就显示在教室屏上

- 只给本班看：这样发就够了，通知只留在教室机上。
- 要给全校看：需要管理员在 `内容 → 通知公告` 里发「全校通知」，会随数据包下发到所有教室机。

!> 勾 `覆盖同标题的旧通知` 后，同名的旧通知会不再显示（不是删掉，编辑窗里还能恢复）。发"本周安排"这种会每周更新的通知时很有用。

== missing | 我要登记没交作业的人 | quick | 缺交名单单独发，屏上会红字提示
1. `发布内容` → 内容类型选 `缺交名单`。
2. 选科目，把没交的同学名字填进去（一行一个）。
3. 点 `发布信息`。

![](missing.jpg)
△ 缺交名单：教室里显示成醒目的一张单

- 名单是整条替换的：这次发 5 个人，屏上就只显示这 5 个。要清空就发一条空的。
- 已经补交的同学不会自动消失，需要你再发一条新的。

== account | 我要切换账号 / 锁住屏幕 | quick | 三种身份怎么切，锁屏怎么开
## 切换账号

`设置 → 用户中心 → 切换账号…`，输入用户名密码即可，**不用关程序**。切完权限立刻生效。

![](account.jpg)
△ 用户中心：当前身份、班级、切换账号都在这一页

## 锁住屏幕（防学生乱点）

按 `Ctrl + L` 锁定，屏幕上只留展示内容；再按一次解锁。快捷键提示就在左侧栏最下面。

## 各自身份能干什么

- `管理员`：全部功能，包括导课表、发布、管理账号。
- `班主任`：改自己班的课表、发作业和缺交、收发数据包。
- `科任老师`：看课表，发所教班级的作业和缺交。
- `电教管理员`：管这台机器的显示，改本班课表。

!> 按钮是灰的，多半是当前账号没这个权限（鼠标停上去会说明原因），不是程序坏了。

== import | 我要导入全校课表（管理员） | quick | 智能导入最省事，先预览再落地
1. `设置 → 数据管理`。
2. 点 `智能导入课表（自动识别模板 · 推荐）`，选 Excel 文件。
3. 预览窗里核对"哪个年级、哪个班、第几列"，不对就改参数，对了点导入。

![](import.jpg)
△ 数据管理：左边导课表，右边发布与自动更新

## 手上没有 Excel

- `下载模板`：按模板填，最稳。
- `手动录入基础课表`：不碰 Excel，按班级一格一格填，还能存成方案下次套用。

!> `.xls` 老格式不支持，先用 Excel / WPS 另存为 `.xlsx`。临时课表文件名要以日期开头（如 `2026-11-24_临时课表.xlsx`），程序靠它判断哪一周生效。

== ledger | 我怎么知道教室机收到了 | quick | 台账看"发了什么、有没有应用"
点今日页的 `打开消息台账`（或消息页里同名按钮）。

- `已应用`：教室机收下并显示出来了。
- `待确认`：已经送到，等电教管理员点确认（勾了"直接增加"的会直接变已应用）。
- `失败 / 无人接收`：教室机关着，或连不上数据源。

## 只看自己发的

台账顶部有 `只看我发的（你的用户名）`，教师机默认就是勾上的 —— 免得在几百条里找自己那一条。

!> 台账里的"已应用"是教室机回报的，不是猜的。看不到回执说明那台机器没联网或没开机，去教室里看一眼比在办公室反复点更省事。

== fix-nosource | 连不上数据源 / 一直提示更新失败 | fix | 先分清是"连不上"还是"没新版本"
先别急着重装，按顺序看三件事。

1. 在 `设置 → 数据管理` 点 `立即检查更新`，看提示的那句话 —— 它会说清是"找不到路径""没有权限"还是"账号密码不对"。
2. 共享路径断过：`设置 → 数据管理 → 自动更新设置… → 共享访问向导`，第 2 步把凭据重存一次。
3. FTP 换过密码：在同一页把账号密码重新填一遍。

## 常见原因对照

- 【找不到网络路径】：办公电脑关机了、IP 变了，或者 445 端口被防火墙拦了。
- 【共享名不存在】：共享被删或改名了，在办公电脑上执行 `net share` 看真实名字。
- 【拒绝访问 / 账号密码不对】：共享权限和 NTFS 权限都要给；凭据失效就重存。
- 【凭据冲突】：这台机器之前用别的账号连过同一台电脑。管理员执行 `net use \\主机 /delete` 断开再连。

!> 数据源不通时程序会自己重试，**不会**卡住不动；重试期间界面照常能用，不用反复点"检查更新"。

== fix-hang | 程序卡住不动 / 点了没反应 | fix | 先等半分钟，再判断是不是真卡
## 先等 30 秒

数据源不通的时候，Windows 连一次网络要等 20 秒左右才放弃。程序已经把这类等待放到后台，界面一般仍然能点；如果正好在做"发布"或"导入"这种大动作，等它做完再操作。

## 还是不动就这样做

1. 不要连续点同一个按钮 —— 会排队执行好几次。
2. 等界面恢复后，看一下屏幕左下角的状态提示写了什么。
3. 反复出现：`设置 → 数据管理 → 自动更新设置…` 里把检查周期调大（比如 30 分钟），或者暂时关掉自动检查。

!> 真的彻底卡死（10 分钟没动静）再结束进程：任务管理器 → 班级公布栏 → 结束任务。重启后已保存的课表、作业都不会丢。

== fix-password | 密码忘了 / 登不进去 | fix | 谁能重置、重置后在哪生效
## 别人忘了，你是管理员

`设置 → 用户中心 → 用户管理…` → 选中那个人 → `修改 / 重置密码`。改完立即生效，不用重启。

## 自己忘了

找另一位管理员帮你重置。学校只有一个管理员账号、且密码也丢了的话，别去手改数据文件 —— 联系维护人，用备份里的用户表恢复更稳。

## 提示"账号已停用"或"不在用户表里"

说明这个账号被停用了，或者发布的用户表里没有它。让管理员在 `用户管理` 里重新启用 / 补上，再发布一次数据包。

!> 学生的 `电教管理员` 账号是开机自动登录用的，密码别随便改 —— 改了那台机器下次开机就停在登录界面。

== fix-class | 班级显示不对 / 课表是空的 | fix | 三种情况，对号入座
## 显示的是别的班

- 普通账号：`设置 → 用户中心`，看自己当前选的班级，点班级名切换。
- 老师账号：默认显示**你自己的课表**；想看某个班就点顶部的 `改看班级课表`。

## 课表整片是空的

1. 这台机器还没导入过课表 → 管理员导入一次，或接收一次数据包。
2. 导入成功但那天没课 → 看看是不是放假 / 调休，`设置 → 数据管理 → 校历 / 调休` 里核对。
3. 只显示了一部分 → 确认导入时选的年级对不对。

!> 一个账号在"用户管理"里没填班级，就什么都看不到 —— **没填班级不等于不限班级**。

== fix-noshow | 发了作业，教室机没出现 | fix | 四个环节，逐个排掉
1. **发出去了吗**：`打开消息台账` 里有没有这张单子？没有就是没发成功，重发一次。
2. **送到了吗**：台账状态是 `待确认` → 教室机收到了，等电教管理员点确认；`失败` → 那台机器没开或没联网。
3. **班级选对了吗**：台账里能看到目标班级，逐个核对。
4. **被旧单覆盖了吗**：同标题的通知勾了"覆盖"会把旧的藏起来，发新的一条看看。

!> 「发布信息」和「发布数据包」是两件事：前者发作业通知，后者发整份课表与账号。作业没出现，别去点发布数据包。

== fix-import | 导入课表认错模板 / 导入后乱了 | fix | 九成是列没对上，改参数重导
## 认错了

智能导入的预览窗里，把"年级""班级""星期在哪一行/列"改对，先看预览再点导入。预览里看到的格子就是导进去的样子。

## 已经导乱了

- 只错了临时课：`设置 → 数据管理 → 清除临时调课 / 代课…`，清完再导。
- 整份都错了：`一键清除全部导入数据`，然后重新导入。**这一步会清掉本机所有课表数据，做题前先备份。**

## 每次都认不对

用 `下载模板` 里的标准格式，或改用 `手动录入基础课表`。老师名带"（代）""（调）"的，导入时会当成调课处理，那是正常的。

!> 导入前先 `备份与恢复` 里做一次备份，出问题能一键退回，比事后逐个修省时间。
