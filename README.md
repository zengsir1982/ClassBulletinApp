# 班级公布栏 ClassBulletinApp

面向教室多媒体屏（Windows 10 及以上，64 位）的班级公布栏：导入全校总课表 → 选班 → 显示当日课表、通知公告、作业公示、缺交名单与自定义便签。

- 当前版本：**v1.0.0**
- 技术栈：C# / WPF（.NET 8），自包含发布，目标机无需预装 .NET 运行时

## 快速上手

1. 安装 / 解压后启动 `ClassBulletinApp`，会自动打开「控制面板」。
2. 「数据管理」→「导入总课表」，选择学校的 `全校班级总课表.xlsx`。
3. 顶部下拉选中自己的班级 → 点「课表悬浮」「通知悬浮」即可显示。
4. 免安装版内附 `使用说明.txt`。

## 主要功能

- **课表**：当日课表悬浮窗，当前节次高亮，支持单双周、调课 / 代课（含临时调代课表导入）、调休换日显示、整周视图、教师个人课表。
- **通知公告**：顶部单行字幕滚动，可设字体 / 字号 / 字色 / 背景与速度，双击即可编辑。
- **作业公示 / 缺交名单 / 自定义便签**：可拖动摆放、拉边沿改大小、双击编辑、锁定防误触，支持 7 种主题与文字格式。
- **桌面背面**：把课表 / 作业 / 缺交名单直接画到桌面壁纸，支持所见即所得排版。
- **悬浮窗体验**：拖动即记住位置与大小；拖到屏幕边沿自动开启「自动靠边隐藏」，拖离自动关闭；支持鼠标穿透、透明度、置顶。
- **上下课提醒**：课前 / 上课 / 下课 / 放学弹窗 + 语音播报。
- **应用快捷方式**：悬浮课表底部可放常用软件 / 文件夹，支持仅显示图标与调节图标大小。

## 编译（开发者）

```bash
dotnet publish ClassBulletinApp/ClassBulletinApp/ClassBulletinApp.csproj -c Release -r win-x64 --self-contained
```

安装版需 [Inno Setup 6/7](https://jrsoftware.org/isinfo.php)：

```bash
ISCC installer/ClassBulletinApp.iss
```

## 数据位置

所有数据保存在 `%APPDATA%\ClassBulletinApp`（课表、通知、作业、设置等 JSON 文件），升级或重新安装不会丢失。

## 已知限制

- 仅支持 64 位 Windows 10 及以上。
- 桌面背面按主屏分辨率渲染，换分辨率或换屏后需重新应用一次。
- 多屏且各屏缩放比例不同时，自动隐藏的边沿唤醒建议实机微调。

## 许可

本项目仅供校内教学使用。课程表等数据属于学校资料，请勿随仓库公开上传。
