# 二一排课 · 课表接口抓包操作手册（微信小程序 / 网页端）

> 用途：当二一教育**不开放官方接口**时，用抓包方式捕获二一排课（微信小程序 / 网页端）查询课表的 HTTPS 请求，
> 提取 URL、鉴权头、响应 JSON，用于后续编写解析原型，直接对接排课系统实现课表与调代课自动同步。
> 配套文档：《01_二一排课接口对接咨询清单.md》

---

## 目标

捕获二一排课查询课表时发出的 HTTPS 请求，提取：

- 请求 URL（含参数）
- 请求头（尤其是鉴权 token / cookie）
- 响应 JSON（课表数据结构）

用于后续编写**解析原型**（独立脚本，不改 App 主代码），验证后能稳定取出
班级 / 星期 / 节次 / 科目 / 教师 / 调代课，再决定如何并入 App。

---

## 抓包目标优先级

1. **PC 网页端（首选，最稳）**：浏览器 F12 即可，无需手机 / 代理 / 证书。
2. **微信小程序（次选）**：需手机 + mitmproxy 代理抓包。
3. **钉钉微应用（退路）**：钉钉会话鉴权更复杂，能抓网页 / 小程序就别碰它。

---

## 方法一：PC 网页端抓包（推荐先试）

1. 电脑浏览器打开二一排课网页端并登录（选好本校、进入课表查询页）。
2. 按 `F12` 打开开发者工具 → 切到「网络 (Network)」标签 → 勾选「保留日志」「XHR / fetch」。
3. 在页面上点「查询课表 / 本周课表」或切换班级。
4. 在网络列表里找课表相关的请求（看「名称」含 `timetable / schedule / course` 之类，或「响应」预览是课表 JSON）。
5. 右键该请求 → 「复制」→「复制为 cURL」，同时「复制请求头」「复制响应」。
6. 把 cURL、请求头、一份完整响应 JSON 存成文件发我。

## 方法二：微信小程序抓包（mitmproxy）

### 准备

- 电脑装 Python，执行 `pip install mitmproxy`
- 手机与电脑连**同一 WiFi**

### 步骤

1. 电脑启动代理：`mitmweb`（带网页界面，默认监听 `0.0.0.0:8080`，管理页 `http://127.0.0.1:8081`）
2. 查电脑局域网 IP（Windows：`ipconfig` 看 IPv4）。
3. 手机 WiFi → 点当前网络 → 代理 → 手动 → 服务器填电脑 IP、端口 `8080`。
4. 手机浏览器访问 `http://mitm.it` → 下载并安装 CA 证书：
   - **安卓**：下载后到「设置 → 安全 → 安装证书」；
   - **iOS**：下载后到「设置 → 已下载描述文件」安装，再到「设置 → 通用 → 关于本机 → 证书信任设置」**手动信任** mitmproxy。
5. 手机打开二一排课微信小程序，登录 / 选好学校班级，点「查课表」。
6. 电脑 `mitmweb` 网页里筛选域名（找 `paike.21cnjy.com` 或 `21cnjy.com` 相关 host），找课表请求。
7. 记录（同方法一的 5）。

### 要捕获的字段清单

- [ ] 完整请求 URL（含 query 参数，如 `schoolId` / `classId` / `week`）
- [ ] 请求方法（GET / POST）
- [ ] 请求头重点：`Authorization` / `Token` / `Cookie` / `User-Agent` / 任何 `x-` 开头自定义头
- [ ] 请求体（POST 时，若是 JSON / 表单）
- [ ] 完整响应体（JSON，原样保存）

## 方法三：钉钉微应用（仅当前两者都失败）

钉钉内二一排课以「微应用」形式存在，请求带钉钉会话鉴权，复现难度高。除非网页 / 小程序都抓不到，否则不建议。

---

## curl 复现模板（拿到样本后填）

```bash
curl 'https://<host>/api/<path>?schoolId=<学校ID>&classId=<班级ID>&week=<周次>' \
  -H 'Authorization: Bearer <token>' \
  -H 'Cookie: <cookie>' \
  -H 'User-Agent: <ua>' \
  --compressed
```

改 `classId` 验证能否拿到其他班；改 `week` 验证能否拿其他周。

---

## 响应 JSON 分析指引（拿到后看这些）

- **班级标识**：找含「八(1)班 / 班级 / class」的字段
- **星期**：找「周一 ~ 周五 / weekday / day」字段
- **节次**：找「第1节 / period / lesson / section」及时间
- **科目 / 教师**：找「subject / course / teacher / 教师」
- **调代课**：找「调 / 代 / 临时 / substitute / replace」标记，或是否有独立「调代课」接口
- 注意：可能按「星期 → 节次 → {科目, 教师}」嵌套，也可能是扁平数组带 `day / period` 字段

## 常见问题

- **小程序里课表空白 / 抓不到请求**：可能微信走了 QUIC(HTTP3) 或做了证书固定。解决：优先改用**网页端**抓；或确认手机代理与证书已正确配置；仍不行则放弃小程序改网页。
- **响应是加密 / 乱码**：二一排课网页端一般是明文 JSON；若遇到加密，记录下 Response 的 `Content-Type` 与原始片段发我判断。
- **token 很快过期**：说明是会话级 token，复现时要连同 Cookie / Refresh 一起保存，后续对接需处理刷新。
