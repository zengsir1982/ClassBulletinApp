# 二一排课系统 · 数据接口对接咨询清单（致二一教育）

> 用途：学校向「二一教育（21cnjy）」咨询是否开放课表数据接口，以便自研班级电子班牌终端对接。
> 配套文档：《02_微信小程序与网页端抓包操作手册.md》（厂商不开放时的逆向退路）。

---

## 一、背景与目标

我校（中山市东凤中学）正在使用二一排课系统管理全校课表与临时调代课。我们计划**自研班级电子班牌终端**（教室多媒体屏，展示当日课表 + 通知 + 调代课提醒），需要**自动、及时地获取课表数据与临时调代课更新**，避免人工反复导出导入。

因此希望了解：二一排课系统是否向学校开放课表数据的**程序化接口**，以便我校自研终端对接。

---

## 二、联系渠道

- 二一排课官网：`paike.21cnjy.com`（页面底部通常有「客服 / 在线咨询 / 电话」）
- 二一教育官方客服（微信 / 电话），建议由学校**教务或信息中心**正式出面联系
- 以「学校信息中心 / 教务」身份沟通，比个人更容易拿到技术资料

---

## 三、开场话术（可直接照读 / 发）

> 老师 / 您好，我是中山市东凤中学的〔教务 / 信息老师〕。我校在用贵司二一排课系统，现在想自己做一个**教室电子班牌**（在教室大屏上显示当天课表和临时调代课）。
> 我们不想每次手工导 Excel，希望系统能**自动把课表数据和调课代课变动推给我们**的终端。
> 看到贵司介绍里说支持「班牌课表展示、实时同步到多端」，想请教：**这套同步背后是否提供数据开放接口（API）或实时推送？能不能开放给我们学校自己研发的班牌终端对接？**

---

## 四、必须问清的核心问题（逐条记录对方答复）

1. **是否有开放接口**：是否提供 REST API 或 WebSocket 实时推送？（区分「查基础课表」和「订阅调代课变动」两类）
2. **协议与数据格式**：接口地址、请求 / 响应格式（是否 JSON）、是否有字段定义文档 / Swagger。
3. **鉴权方式**：用什么鉴权（Bearer Token / AppKey / 学校级账号）？Token 有效期与刷新机制？
4. **调代课如何获取**：临时调课 / 代课是实时推送，还是需要我们轮询？能否增量获取（只给变动）？
5. **频率与配额**：调用频率限制、每日 / 每月配额、是否有沙箱测试环境。
6. **开放范围与费用**：接口是否仅对「合作班牌硬件厂商」开放，还是允许学校自研终端？是否收费（一次性 / 年费）？
7. **文档与支持**：是否有对接文档、SDK、示例代码、技术支持对接人。
8. **合规**：学校自研终端读取本校数据是否被允许，有无数据使用条款限制。

---

## 五、退路问题（若对方说「没有开放接口」）

- 是否提供**标准化定时导出**（Excel / Word / CSV）文件，字段固定、可由程序自动解析？
- 是否接受「班牌合作」准入，把我校纳入其班牌生态（哪怕只拿数据）？
- 能否提供其班牌对接所用接口的规范（哪怕是非公开文档）供我校参考？

## 七、基于答复的决策

- **若给开放接口** → 进入技术对接，按接口写 `ErYiClient`（与 `TencentDocClient` 同位置），保留腾讯文档 / 手动导入兜底。
- **若只合作硬件** → 放弃官方接口，走「抓包逆向」（见配套手册）或维持手动导出。
- **若完全无接口且无导出规范** → 维持现有腾讯文档手动方案。
