# 二一排课 · 网页端「一键捕获脚本」（免抓包）

> 你不需要懂抓包。只要照下面 5 步操作，把捕获到的内容发给我，我就能写出解析程序。
> 适用：在 **电脑浏览器** 打开 `https://paike.21cnjy.com/` 登录后查询课表。
> 配套：《01_二一排课接口对接咨询清单.md》《02_微信小程序与网页端抓包操作手册.md》

---

## 为什么用脚本而不是手抓

二一排课的课表数据在登录后的会话里，必须你本人登录才能拿到，我无法替你操作。
「控制台捕获脚本」会**自动监听浏览器发出的所有网络请求**，从中挑出「看起来像课表」的那一条，
把它的 网址 / 请求头 / 返回数据 抓出来，你一键复制给我即可——不用在 Network 面板里翻找。

---

## 操作步骤（全程约 1 分钟）

1. 电脑浏览器打开 `https://paike.21cnjy.com/`，**登录**你的学校账号。
2. 进入「课表查询 / 班级课表」页面（先不要点查询）。
3. 按 `F12` 打开开发者工具 → 切到 **Console（控制台）** 标签。
4. 把本文最下方「捕获脚本」整段复制，粘贴到控制台里，**回车**运行。
   - 看到蓝色提示「[捕获脚本已启动]」即成功。
5. **回到页面，正常点击「查询课表」或切换班级**，让课表显示出来。
   - 脚本会自动打印一条绿色「[课表接口捕获]」的信息。
   - 然后**在控制台输入 `copyCap()` 并回车**——完整内容已复制到剪贴板。
6. 把剪贴板内容（或直接把 `copyCap()` 的输出）**发给我**即可。

> 若想看捕获到的所有请求，输入 `listCap()` 回车，会列出每条的得分/方法/网址，挑 `score` 最高的那条用 `copyCap()` 复制。

### 需要两份数据（原始课表 + 临时课表）时

二一排课的「原始课表」和「临时课表（调代课）」通常是**两个不同查询**，对应两条不同的接口请求。脚本会**把两次查询都记下来**，做法：

1. 脚本运行后，先查询**原始课表** → 控制台出现绿色捕获 → 输入 `copyCap()` 回车，把这份复制下来（先存到记事本或发我）。
2. 再到页面查询**临时课表（调代课）** → 控制台又出现绿色捕获 → 再输入 `copyCap()` 回车，复制第二份。
3. 如果两次绿色捕获混在一起分不清，用 `listCap()` 查看全部捕获（带序号和得分），然后：
   - `copyCap(0)` 复制第 0 条、`copyCap(1)` 复制第 1 条……按序号分别复制两份。
4. 把两份（原始 + 临时）都发我。

> 提示：即使某条没触发绿色自动打印（得分偏低），它也会被 `listCap()` 列出来，用 `copyCap(序号)` 照样能复制。

---

## 候选接口如果没自动出现，怎么办

- 确认第 4 步脚本**先于**查询运行（先粘脚本回车，再点查询）。
- 若控制台没有任何绿色捕获，可能是课表数据是页面初次加载时一次性返回的（不是单独请求）。
  这时改用兜底：F12 → **Network（网络）** 标签 → 刷新页面 / 点查询 → 在列表里找响应预览像课表的请求
  （名称可能含 `timetable / schedule / course / query / 课表`），右键 → 复制 → **复制为 cURL**，连同响应一起发我。

## 捕获脚本（复制下面全部内容）

```javascript
(function(){
  // 1) 先定义全局函数（放最前，确保即使后面 hook 失败也可用 listCap/copyCap）
  window.__capStore = window.__capStore || [];
  window.__cap = window.__cap || null;
  window.listCap = function(){
    var s = window.__capStore;
    if(!s.length){ console.log('✅ 脚本已运行，但还没有捕获到请求。请去页面查询课表，或确认脚本先于查询运行。'); return; }
    console.log('已捕获 ' + s.length + ' 条请求：');
    s.forEach(function(it,i){ console.log(i, 'score=' + it.score, it.method, it.url.slice(0,110)); });
  };
  window.copyCap = function(i){
    var c;
    if(typeof i === 'number'){ c = window.__capStore[i]; }
    else { c = window.__cap || window.__capStore[window.__capStore.length-1]; }
    if(!c){ console.log('还没有可复制的捕获。先粘贴脚本回车 → 查询课表 → 再 copyCap()'); return; }
    var out = 'URL: ' + c.url + '\nMethod: ' + c.method + '\nHeaders: ' + c.reqHeaders + '\nBody: ' + c.body + '\n\n---RESPONSE---\n' + c.respText;
    try{ copy(out); console.log('已复制' + (typeof i==='number' ? '第'+i+'条' : '最新一条') + '完整内容到剪贴板，直接粘贴给我即可'); }
    catch(e){ console.log(out); }
  };
  // 2) 再挂网络监听（异常保护，失败也不影响上面函数）
  try{
    function hdrToObj(h){
      if(!h) return {};
      if(typeof Headers!=='undefined' && h instanceof Headers){ var o={}; h.forEach(function(v,k){o[k]=v}); return o; }
      if(typeof h==='object') return h;
      return {};
    }
    function looksLikeSchedule(t){
      if(!t) return 0;
      var keys=['科目','教师','星期','班级','第1节','课表','schedule','timetable','course','teacher','代课','调课'];
      var score=0;
      for(var k=0;k<keys.length;k++){ if(t.indexOf(keys[k])>=0) score++; }
      if(t.length>500) score+=1;
      return score;
    }
    function record(url,method,reqHeaders,body,respText){
      var score=looksLikeSchedule(respText);
      var item={url:url,method:method,reqHeaders:reqHeaders,body:body,respText:respText,score:score,time:new Date().toLocaleTimeString()};
      window.__capStore.push(item);
      if(score>=3){
        console.log('%c[课表接口捕获✅] score='+score,'color:#0a0;font-weight:bold');
        console.log('URL:',url);
        console.log('Method:',method);
        console.log('Request Headers:',reqHeaders);
        if(body) console.log('Request Body:',body);
        console.log('Response(前2000字):',respText.slice(0,2000));
        window.__cap=item;
      }
    }
    var _fetch=window.fetch;
    window.fetch=function(input,init){
      var url=typeof input==='string'?input:(input&&input.url)||'';
      var method=(init&&init.method)||'GET';
      var headers=init&&init.headers;
      var body=init&&init.body;
      return _fetch.apply(this,arguments).then(function(resp){
        var clone=resp.clone();
        clone.text().then(function(t){ record(url,method,JSON.stringify(hdrToObj(headers)),typeof body==='string'?body:JSON.stringify(body),t); }).catch(function(){});
        return resp;
      });
    };
    var _open=XMLHttpRequest.prototype.open;
    var _send=XMLHttpRequest.prototype.send;
    XMLHttpRequest.prototype.open=function(m,u){ this.__m=m; this.__u=u; return _open.apply(this,arguments); };
    XMLHttpRequest.prototype.send=function(b){
      var self=this;
      this.addEventListener('load',function(){
        try{ record(self.__u,self.__m,JSON.stringify(self.getAllResponseHeaders()),typeof b==='string'?b:JSON.stringify(b),self.responseText); }catch(e){}
      });
      return _send.apply(this,arguments);
    };
    console.log('%c[捕获脚本已启动✅] 现在去查询课表，控制台会自动捕获。运行 listCap() 看全部，copyCap() 复制。','color:#06c');
  }catch(e){
    console.log('%c[捕获脚本已启动✅] 但网络监听初始化失败，仍可手动记录。运行 listCap()/copyCap() 查看已捕获。','color:#c60', e);
  }
})();
```

> **运行成功的标志**：粘贴回车后，控制台立刻打印蓝色 `[捕获脚本已启动✅]`。若没有这行，说明脚本没跑（多半是漏了"允许粘贴"后再粘贴一次这步）。
> **自检**：运行后输入 `listCap()` 回车，若显示"脚本已运行，但还没有捕获到请求"= 函数可用；若仍报 `listCap is not defined` = 脚本未运行，请重来。

## 抓取全量数据并直接存成文件（推荐，避开聊天截断）

> ⚠️ 实测结论：`substitute-list` / `grade-tree` / `class-lectures` **都不按请求里的 `startDate/endDate` 过滤**（日期参数被服务端忽略，一次性返回全部历史）。
> 所以不要试图"按日期区间重抓"——正确做法是**抓一次全量，解析时在本地按"今天是否落在 validStart~validEnd 且未失效"过滤**（原型已内置此逻辑）。
> 另外，大段 JSON 在聊天里会被截断、无法直接存盘。用下面命令**直接下载成 .json 文件**，最稳妥。

在已登录的 `paike.21cnjy.com` 控制台粘贴（把文件名/接口换着用即可）：

```javascript
// 通用下载器：抓取任一接口并保存为本地文件
function dlJSON(url, name){
  fetch(url, {credentials:'include'}).then(r=>r.json()).then(j=>{
    var blob=new Blob([JSON.stringify(j,null,2)],{type:'application/json'});
    var a=document.createElement('a'); a.href=URL.createObjectURL(blob); a.download=name; a.click();
    console.log('✅ 已下载 '+name+'（记录数：'+(j.data?j.data.length:'?')+'），放到 数据对接方案/data/ 覆盖同名文件即可');
  }).catch(e=>console.log('❌',e));
}

// 1) 调代课（全校，全量）
// 全校三个年级各有独立 projectId（多年级配置）。每个年级各抓三份：
const PID_8 = '77cc8c2dba034b04b0ccb77c542e20d1'; // 八年级（已确认）
const PID_7 = '818007cc3510c7f916204a5043010955'; // 七年级（已确认，见 data/project-list.json）
const PID_9 = '9a2c21ed598a5abeb8ed7c3ad3c56d98'; // 九年级（已确认，见 data/project-list.json）

// 1) 调代课（某年级，全量）→ 文件名带年级，避免跨年级覆盖
dlJSON('https://paike.21cnjy.com/query/substitute-list?projectId='+PID_8+'&teacherId=', 'substitute-list-八年级.json');

// 2) 年级树（全校班级列表，拿 30 个 classId）
// dlJSON('https://paike.21cnjy.com/query/grade-tree?projectId='+PID_8, 'grade-tree-八年级.json');

// 3) 某班基础课表（把 CID 换成 grade-tree 里的真实 classId）
// dlJSON('https://paike.21cnjy.com/query/class-lectures?projectId='+PID_8+'&classId=CID', 'class-lectures-八年级-<CID>.json');
```

- 下载后把文件放进 `数据对接方案/data/`。命名按年级区分：`grade-tree-<年级>.json` / `class-lectures-<年级>-<classId>.json` / `substitute-list-<年级>.json`。`parse_eryi.py` 已支持扫描带年级的文件并合并；单文件的 `grade-tree.json`/`substitute-list.json` 也兼容。
- **批量下载全校基础课表（含多年级）**：直接用 `batch_download_classes.js`——它内置 `PROJECTS` 数组（每个年级一个 projectId），依次拉每个年级的 grade-tree→逐班 class-lectures→substitute-list，自动按年级命名存盘（带 300ms 节流）。**三个年级的 projectId 现已全部确认，并集中在 `data/project-list.json`（排课项目列表，含每级每日 8 节标准时间表与 大课间/眼保健操/午休 固定项坐标）。`batch_download_classes.js` 的 `PROJECTS` 已填好七/八/九三项，开箱即用，无需再手动填 PID。** 在控制台粘贴整段回车，浏览器连续弹出下载。
- 若浏览器阻止了自动下载，看地址栏右侧的下载权限提示，允许后再点一次。
